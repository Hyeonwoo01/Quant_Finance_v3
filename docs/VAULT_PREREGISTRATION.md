# Vault 사전 등록 — 한국 주식 월간 상대 수익률 (초안)

> **상태: 초안. 아직 확정하지 않았다.** 확정은 사용자가 검토한 뒤 이 상태 줄을 "확정"으로 바꾸는 커밋으로 하고, 그 커밋 해시를 Vault 평가 기록에 남긴다. 초안이 main에 있어도 확정이 아니다. 확정 전에는 Vault 시세를 읽지 않고, 확정 뒤에는 이 문서의 어떤 항목도 바꾸지 않는다. 바꿔야 하면 새 질문으로 보고 새 Vault 구간을 기다린다(가이드 7-11, 7-12).

## 1. 무엇을 검증하나

개발 구간(2010~2024-10)에서 찾은 월간 종목 선택 신호가 **처음 보는 구간에서도 비용 후 초과수익을 내는지** 한 번만 확인한다. 개발 구간 결과는 모두 `탐색 결과`(DSR < 0.95)였다(가이드 8-5).

## 2. 고정하는 것

| 항목 | 값 |
|---|---|
| 코드 | 확정 커밋의 `evaluation/run_experiment.py`와 그 의존 모듈. 하이퍼파라미터는 `engines/prediction_engine.py` `PARAMS` 그대로 |
| 타깃 | `RET_21D`: 판단일 D 시가 진입, D+21세션 시가 청산 (가이드 7-3) |
| 판단 간격 | 21세션 (월 1회), Vault 첫 세션부터 |
| 피처 가용 시각 | 지금 규칙 그대로: KRX 일별 자료는 다음 세션 13:00부터 쓴다고 보고, D 08:30 판단에는 D−2 종가까지 쓴다. 공개 시각 관측(`pubcheck`)으로 규칙을 완화하더라도 **그 신호는 이 Vault로 검증하지 않은 것**으로 본다 |
| 유니버스 | 그날 거래대금 하위 20% 제외, 이력 252세션 이상 |
| 포트폴리오 | Long-only 점수 상위 10% 같은 비중 매수, 보유 종목은 상위 20% 안이면 유지, 운용금액 1억 원 |
| 비용 | `costs_v2` 세 시나리오(base, conservative, stress). 매도세율은 결제일(T+2) 기준. 2024~2026 세율은 보도·법무법인 자료로 확인했고 국세법령 원문 대조는 남았다 |
| 기준 | 같은 유니버스에서 진입 가능한 종목 전체의 같은 비중 평균 (비용 없음) |
| 학습 | Purged walk-forward와 같은 방식. Vault 안에서 12개월마다 다시 학습하고, 각 학습은 그 시점에 정답이 나와 있던 행만 쓴다(purge + 5세션 embargo) |
| Vault 구간 | 2024-11-01 ~ 정답(D+21 시가)이 있는 마지막 판단일. 판단일은 약 23개 |

## 3. 후보 (두 개만)

| | 모델 | 피처 | 개발 구간 base 초과 (95% 신뢰구간) | 고른 이유 |
|---|---|---|---|---|
| **H1 (주)** | Ridge | `price_v1` | +13.3% [8.5%, 17.5%] | 비용 후 성과와 DSR이 가장 높다 |
| **H2 (보조)** | GBM | `price_v1` | +8.2% [4.6%, 12.0%] | IC가 가장 높고 유동성 높은 종목에서 강하다 (Ridge와 다른 종류의 신호) |

재무(`fund_v1`)·시장 상태(`mkt_v1`) 피처는 개발 구간에서 성과를 올리지 못해 후보에서 뺀다. 다른 변형은 평가하지 않는다.

## 4. 채택 기준 (미리 정함)

각 후보는 아래 **세 가지를 모두** 만족해야 `검증된 신호`가 된다. 두 후보에 Holm 보정을 쓴다(H1 먼저 α = 0.025, H1이 통과하면 H2는 α = 0.05).

1. **비용 후 초과수익:** base 비용 후 판단일별 초과수익의 평균이 0보다 크다. 블록 부트스트랩(블록 6, 개발 구간과 같음, 10,000회) 단측 p값이 보정된 α보다 작다.
2. **보수적 비용에서도 양수:** conservative 비용 후 연율 초과수익 > 0.
3. **순위 예측력:** 판단일별 Rank IC 평균 > 0, NW t > 1.65.

함께 보고하되 채택 기준에는 넣지 않는 것: stress 비용 결과, 최대 낙폭, 회전율, 연도별 결과, 거래대금 5분위별 IC, 용량 제한으로 현금이 된 비율.

## 5. 결과를 어떻게 다루나

- **통과:** `검증된 신호`로 표시하되, 판단일이 약 23개라 신뢰구간이 넓다는 점을 같이 적는다. 실제 운용 판단은 이후 정상 운영 기록(예측 기록 정산, 가이드 7-10)으로 계속 확인한다.
- **실패:** `탐색 결과`로 남긴다. Vault 결과를 보고 모델·피처·비용·기준을 고쳐 다시 평가하지 않는다. 같은 질문을 다시 검증하려면 2026-11 이후의 새 구간이 충분히 쌓여야 한다.
- 어느 쪽이든 결과와 이 문서의 확정 커밋을 실험 기록에 남긴다.

## 6. 검정력 (미리 적어 둔다)

개발 구간 Ridge의 초과 샤프는 연 1.9(월 0.55)였다. 효과가 그대로라면 판단일 23개에서 t ≈ 0.55 × √23 ≈ 2.6이라 통과할 가능성이 크다. 그러나 다중 시행으로 고른 결과는 대개 줄어든다. 효과가 절반이면 t ≈ 1.3으로 기준을 넘기 어렵다. **실패해도 신호가 없다는 증거는 아니며, 이 크기의 Vault로는 큰 효과만 확인할 수 있다.**
